Single-page responsive Arabic website for **شركة حصن العدالة للمحاماة والاستشارات القانونية**.

## What is included

- Arabic RTL responsive design
- Sticky navigation + mobile menu
- Hero section and trust indicators
- Legal services and practice areas
- About, values, team, and work methodology
- Google rating block linked to the official Maps listing
- Office location embed
- Call and WhatsApp floating actions
- Consultation form that opens a pre-filled WhatsApp message (no backend required)
- Basic SEO metadata + LegalService schema
